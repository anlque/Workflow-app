# Starter Workflows

Locusora installs three offline example Workflows as starter-content version 2:

| Workflow | Purpose |
| --- | --- |
| Quick Focus | A single ten-minute Focus Phase for starting immediately. |
| Balanced Flow | A focus–break–focus rhythm with contrasting bundled environments. |
| Reward Journey | A Focus journey demonstrating Reward Dice, one reroll and a Bonus Reward Phase for every result. |

The examples are ordinary local Workflows. Users may edit, reorder, duplicate,
export or delete them through the same paths as any Workflow they create. Once
version 2 is recorded as complete, later startup never restores an example that
the user changed or deleted.

The current Workflow Domain has no description field and Locusora has no
separate onboarding UI. This document is therefore the bounded onboarding copy
for SEED-003; introducing visible descriptions is future UI/onboarding work, not
hidden seed metadata.

Every Environment uses a Role reference owned by the version-1 starter Assets.
No network provider or direct seeded Asset ID is required to validate or launch
the examples.
